# 大摆锤 3D 结构演示（Three.js 多文件项目）

基于 **Three.js r160（MIT 协议，可商用）** 的 Web 3D 大摆锤（Pendulum Ride）游乐设备演示。
支持轨道视角控制、实体/线框透视切换、真实往复摆动动画、三种天气切换，以及 8 大部件的点击标注讲解，全部 UI 与注释均为中文。

---

## 一、目录结构

```
mode14/
```

## 二、运行方式

项目使用 ES Module，浏览器要求页面通过 **HTTP 服务**访问（直接双击 `index.html` 用 `file://` 打开会因模块跨域限制无法运行）。

### 方式 1：Python 内置服务器（推荐，无需安装依赖）

```bash
# 在项目根目录 mode14/ 下执行
python -m http.server 8080
```

浏览器访问：<http://localhost:8080>

### 方式 2：Node.js 环境

```bash
npx serve .
# 或
npx http-server -p 8080
```

### 方式 3：VS Code

安装 **Live Server** 扩展，右键 `index.html` → `Open with Live Server`。

> Three.js 通过 jsDelivr CDN 加载，首次运行需联网。离线部署可执行
> `npm i three@0.160.0` 后把 `node_modules/three` 放到项目内，并修改
> `index.html` 中 importmap 的两个地址指向本地路径。

## 三、功能说明

### 1. 视角控制（OrbitControls 轨道控制器）

| 操作 | 效果 |
| --- | --- |
| 鼠标左键拖拽 | 360° 环绕旋转查看模型 |
| 鼠标滚轮 | 拉近 / 拉远相机（限制在 8m ~ 95m） |
| 鼠标右键拖拽 | 平移相机 |
| 触屏单指 / 双指 | 旋转 / 缩放（移动端） |

带阻尼惯性，视角转动顺滑；相机被限制在地面以上，不会穿到地下。

### 2. 实体 / 透视线框模式

点击控制面板的 **【透视线框模式】** 按钮，整机材质在实体与线框之间切换。
线框模式下可直接看清 A 型塔架内部、摆动主轴、桁架摆臂腹杆、回转支承、驱动齿轮等内部结构。

### 3. 运转动画（真实游乐设备逻辑）

- **摆角公式**：`摆角 = 包络(t) × 100° × sin(2π·t / 7s)`
  - 极限摆角 **±100°**，往复周期 **7 秒**，符合真实大摆锤参数；
  - `smoothstep` 包络模拟设备 **缓启动 → 摆幅渐增 → 满幅平稳运行** 的过程；
  - 暂停时保持当前姿态，复位时摆臂与座舱回到初始位置。
- **座舱自转**：圆盘以 0.65 rad/s 绕竖直轴匀速旋转，16 个座椅随圆盘自转、
  又随摆臂做圆弧摆动，形成“摆动 + 自转”复合轨迹。
- **机械层级保证不穿模**：`摆动主轴节点 → 大摆臂 → 座舱回转盘 → 座椅/压杆`
  全部为父子节点关系，座椅严格跟随上级刚体运动，不存在错位穿插。
- **播放 / 暂停 / 复位** 三个按钮 + **速度倍率滑块（0.2× ~ 2.5×）**，
  倍率只改变推进速度，不压缩相位，换向节奏始终自然。
- 左上角 HUD 实时显示运转状态、当前摆角与速度倍率。

### 4. 天气切换

| 天气 | 表现 |
| --- | --- |
| ☀ 晴天 | 蓝天、暖色强日光、清晰远景、正常阴影 |
| ☾ 夜晚 | 深蓝黑夜空、冷色月光、园区暖光照明、900 颗星点 |
| ☂ 雨天 | 阴沉天空、**轻微线性雾效**（28m 起衰减）、2600 条动态雨线、整体压暗 |

雨线使用 `LineSegments` + 动态 `BufferAttribute` 实现，落到地面自动回收到雨区顶部循环。

### 5. 部件标注与讲解

可直接在 3D 场景中 **点击设备部件**（自动区分点击与拖拽，拖拽视角不会误触发），
被选中部件以蓝色自发光高亮，右侧面板弹出该部件的结构、作用与功能讲解；
也可在右侧 **部件目录** 中直接点选。共标注 8 个主要部件：

1. 底座支撑钢架
2. 主旋转支座（A 型塔架）
3. 摆动主轴
4. 大摆臂
5. 座舱（乘客座椅）
6. 驱动电机结构
7. 安全压杆
8. 限位防护结构

讲解文案维护在 `js/parts.js`，可直接增删修改。

## 四、关于 3D 模型来源的说明

公开素材站（Sketchfab / TurboSquid 等）上的大摆锤 GLB 模型授权条款差异较大，
且下载地址不稳定，为保证项目 **可商用、可离线、部件可精确点击**，
本项目采用 Three.js 基础几何体 **程序化 1:1 建模**：

- 每个部件独立成组并写入 `userData.partId`，点击拾取与讲解一一对应；
- 线框透视只需切换材质标志，无需处理外部模型复杂的网格层级；
- 运动层级严格按真实机械结构搭建，动画天然无穿模。

如确需引入自有授权的 GLB 模型，可按以下方式接入（示例）：

```js
import { GLTFLoader } from "three/addons/loaders/GLTFLoader.js";

new GLTFLoader().load("./assets/pendulum.glb", (gltf) => {
  gltf.scene.traverse((obj) => {
    if (obj.isMesh) {
      // 按 GLB 中各网格的命名映射到部件 id
      obj.userData.partId = nameToPartId(obj.name);
      obj.castShadow = obj.receiveShadow = true;
    }
  });
  scene.add(gltf.scene);
});
```

模型需保证摆臂与座舱挂在对应摆动节点下，才能复用现有动画逻辑。

## 五、浏览器要求

- 支持 WebGL2 的现代浏览器（Chrome / Edge / Firefox / Safari 近两年版本）；
- 首次加载需联网获取 CDN 上的 Three.js；
- 建议独立显卡或较新核显，阴影贴图分辨率为 2048×2048。
